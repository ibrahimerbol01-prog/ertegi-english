# Слова карточек легенд без перевода в глоссарии

Черновик, 06.11.2026. Исполнитель: Madiii55 (Claude). **Данные в `src` не правились.**

- **Что проверено.** Английский текст 13 карточек из `src/data/legends.ts`: сцены, вопросы, варианты ответов, `fact.en`. Каждое слово искали в глоссарии `WORD_TRANSLATIONS` (`src/constants.ts`) по тем же ключам, что и `glossKey` из `src/utils/gloss.ts`: слово как написано, без 's, только буквы.
- **Итог.** Из 1927 словоупотреблений без перевода 361 (18,7 %), это 183 разных слова. Пустых значений в глоссарии нет (0 из 1626 ключей).
- **Русских переводов в глоссарии нет вообще.** `WORD_TRANSLATIONS` — словарь только «английский → казахский», поэтому колонка `ru` — новое предложение для всех слов.
- **Файл** `legend-glosses.csv`: `word,pos,kk,ru,source,cards`. В колонке `cards` — id карточек, где встречается слово (это и есть список мест).
- **Ключи — словоформы, а не леммы:** died, enemies, wrote. Так ищет `glossKey`. Перевод дан для формы, а лемма указана в `source`.
- **Имена собственные.** Казахское написание взято из полей `kk` той же карточки, где оно есть («как в legends.ts»). Остальные имена (Әбілмансұр, Құртқа, Тайбурыл, Омбы) надо проверить по источнику.
- **Ограничения.** Перевод не сверен поштучно со словарём, это указано в каждой строке. Токены `th` (из 18th) и `bc` (BC) — не слова. Возможно, их стоит обрабатывать в `glossKeys`, а не в глоссарии.

Команда для проверки — та же логика на Python: `glossKeys` повторён в скрипте задания (свёртка диакритики NFD, нижний регистр, три ключа).
