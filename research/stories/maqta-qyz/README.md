# «Мақта қыз бен мысық» — адаптация A1–C1 (черновик, НА ПРОВЕРКУ УЧИТЕЛЮ)

Черновик по методу ertegi-story-method. **В приложение не добавлен**: `src/` не менялся. Сказка появится в приложении только после проверки учителем, отдельным заданием.

## Источник

- Основной текст: «Мақта қыз бен мысық ертегісі», ertegiler.kz, https://ertegiler.kz/story/makta-kyz-ben-mysyk (открыт 05.11.2026). Там же мультфильм: https://ertegiler.kz/cartoon/makta-kyz-ben-mysyk.
- Источник указан на сайте как «Қазақ халқының ұлттық ертегілері». **Народная / школьная версия, автор не подтверждён.** Авторство «Алтынсарин» из школьных конспектов не подтверждено, поэтому здесь не указано.
- Школьные конспекты (infourok.ru, stud.kz) я не открывал. Звенья и порядок цепочки в вариантах различаются, здесь взят вариант ertegiler.kz. Тексты — пересказ своими словами, без цитат.

Сюжет по ertegiler.kz: Мақта қыз убирается и находит мейіз, зовёт кошку, кошка не идёт, девочка съедает изюм сама. Кошка грозится пролить её қатық, девочка грозится отрезать хвост, обе угрозы исполняются. Кошка просит хвост, девочка требует қатық. Цепочка: корова → листья, дерево → вода, девочки → сағыз, лавочник → яйцо, курица → зерно; мышь, которая роет нору, даёт горсть проса. Обратно по цепочке: просо → яйцо → сағыз → вода → лист → қатық → хвост возвращён.

## ПРОВЕРИТЬ УЧИТЕЛЮ

1. **Порядок и звенья цепочки** (корова → дерево → девочки → лавочник → курица → мышь) — по ertegiler.kz. В других вариантах звенья и порядок другие. Подходит ли этот вариант?
2. **Концовка.** У ertegiler.kz: хвост возвращён. «They are friends again» / «After that they were friends» (A1–A2) и «quarrel laid to rest» (C1) — из общего ядра вариантов (помирились), в тексте ertegiler.kz прямо не сказано.
3. **Мораль (опора 7)** — моя формулировка: «делись; исправляй вину трудом», в духе раздела «чему учит» на сайте («делиться и мириться после ссоры»).
4. **Отрезанный хвост** — событие самой сказки. Дано без подробностей; в видеосцене момент не показан. Подходит ли для 8–14 лет?
5. **Перевод реалий:** сағыз = «chewing gum» (в сказке — природная жевательная смола); қатық = «sour milk / qatyq». «Maqta = cotton» (C1) — значение слова мақта.
6. **Выбор (опора 4)** и мысли кошки (B2, C1) — приём метода и языковое развитие уровня, а не фольклорное содержание.
7. **Переводы в glossary.json** сделаны исполнителем (Claude) — проверить носителю.
8. Уровень текстов — по лимитам навыка; соответствие классу проверяет учитель в пилоте.
