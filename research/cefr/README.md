# External vocabulary scale for the corpus profile (R6)

These two files are the outside reference the corpus profile (`docs/corpus.md`) compares our texts with. They are used only by `npm run corpus` and the tests; the app never loads them.

- `cefrj-vocabulary-profile-1.5.csv`: The CEFR-J Wordlist Version 1.5, compiled by Yukio Tono, Tokyo University of Foreign Studies. Levels A1–B2. Copyright Tono Laboratory, TUFS. Terms (from the source repository): free for research and commercial use, provided the dataset is cited properly.
- `octanove-vocabulary-profile-c1c2-1.0.csv`: Octanove Vocabulary Profile C1/C2, version 1.0, Octanove Labs. Licensed under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).

Both copied unchanged from https://github.com/openlanguageprofiles/olp-en-cefrj, commit d4e45b75b38f27b30dfc5c44d8c571aec7e7092f (2020-03-25).

How to cite: The CEFR-J Wordlist Version 1.5. Compiled by Yukio Tono, Tokyo University of Foreign Studies. Retrieved from http://www.cefr-j.org/download.html. Octanove Vocabulary Profile C1/C2 (ver. 1.0), Octanove Labs.

Note: CEFR-J is the CEFR adapted for learners of English in Japan. Its word levels are a reasonable external scale for school learners of English as a foreign language, but they were not built for Kazakh learners.
