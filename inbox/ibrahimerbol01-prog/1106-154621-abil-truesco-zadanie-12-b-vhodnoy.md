# Задание 12 (Б): входной тест уровня v1 — PR

Итог: сделано. https://github.com/ibrahimerbol01-prog/ertegi-english/compare/main...feat/placement-test?expand=1 — построен поверх feat/profile-nick-avatar (порядок: dom-tests → profile → placement).
20 пунктов «знаешь ли слово»: по 3 слова A1–C1 из нашего словаря (только сущ./глаг./прил., с примером из сказок, если есть; не встречаются на более низком уровне, иначе «man» C1 узнал бы любой новичок) + 5 своих псевдослов (sample, на проверку учителю). Оценка: уровень засчитан при 2 из 3, подъём от A1 до первого пробела, больше 1 «да» на псевдословах = «ненадёжно, пройди ещё раз». Итог «Шамамен A2» + «это не экзамен» + кнопка «Ертегіні оқу: A2». Правило — гипотеза. Главная: предложение для ученика (не для учителя), «Кейін» скрывает его; в профиле всегда можно пересдать. Хранится только на устройстве, событий нет.
Исследовательская сборка: alias на PlacementCheck.off; сборкой проверено — нет чанков и слов теста.
Проверки: lint ✓, typecheck ✓, test ✓ (39 файлов, 548; новых 16), build ✓. Чанк 1,7 КБ gzip, начальный JS +1,3 КБ к main вместе с (А) (строки DICT). Руками за входом не проверял (нет доступа к рабочему Supabase).
