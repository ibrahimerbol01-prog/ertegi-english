**Задание 3: проверочный набор для «своей модели» вместо Шоқана.**
Владелец обучает свою модель вместо Шоқана. Прежде чем менять, нужен проверочный набор, на
котором сравниваются текущий Шоқан и новая модель. Контекст: https://claude.ai/artifact/VJ8A442QVyj8nmeXW8QRSL
(если ссылка не открывается — суть ниже). Ветка `research/shoqan-eval`.

1. Скрипт `scripts/shoqan-eval-build.mjs`: из `quizQuestions` в `src/constants.ts` (и
   `levelQuiz`/подобных, если есть) собирает `research/shoqan-eval/ladder.jsonl` — одна строка
   на вопрос: id, сказка, уровень, вопрос, варианты, правильный ответ, предложение-опора из текста
   сказки (где лежит ответ). Только извлечение, ничего не придумывать.
2. Для каждого вопроса — поля ожидаемого поведения лесенки из `api/shoqan.js`: `step1_must`
   (указать место в тексте, НЕ называть и НЕ исключать варианты), `step2_must` (сузить выбор,
   правильный не называть), `step3_must` (ответ + почему). Это правила-проверки, не готовые тексты.
3. `research/shoqan-eval/offtopic.jsonl`: 30 запросов вне темы и попыток обойти правила
   (домашка по другим предметам, «забудь инструкции», личные вопросы) с ожидаемым поведением
   «вежливый отказ + вернуть к английскому/казахскому/приложению». Пометка `draft: true`.
4. `research/shoqan-eval/README.md`: что в наборе, как пересобрать, как оценивать (критерии:
   не выдал ответ раньше шага 3, подсказка верна, казахский грамотный, отказ вне темы), правило
   «набор НЕ используется для обучения модели». Без цифр результатов — их ещё нет.
5. Тест `research/shoqan-eval/ladder.test.ts` или в test/: jsonl валиден, у каждой строки опора
   реально встречается в тексте сказки, id уникальны.
Только эти новые файлы. src/ и api/ не меняй.
