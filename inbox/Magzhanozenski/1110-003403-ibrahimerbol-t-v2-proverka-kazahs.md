# T-V2: проверка казахских строк интерфейса

Задача T-V2 → Магжан. Проверка казахских строк интерфейса.
Зачем: продукт. Жюри и школьники увидят казахский интерфейс; опечатки и ошибки вредят доверию. Приоритет НИЖЕ T-M2, T-M3, T-L2.
Что сделать: прочитай казахские строки в src/dict.ts (kk) и в PrivacyPolicy.tsx (казахская часть), найди ошибки грамматики, орфографии и неестественные формулировки. Исправления внеси только в тексты: ветка fix/kk-strings-review, один PR, без изменений ключей, структуры и логики; тест на паритет kk/en должен пройти; в PR приложи таблицу «было / стало / почему». Если сомневаешься, не меняй, а выпиши в комментарий PR вопросом к владельцу (он носитель казахского).
Не трогать: английские и русские строки, API, миграции, зависимости, исследовательскую сборку.
Как проверить: npm run lint, npm test, npm run build зелёные.
Риск: R1 (только PR на ревью, мерж делает владелец после питча).
Если лимит Claude кончается, напиши, что сделано, и остановись.
