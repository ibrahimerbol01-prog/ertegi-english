# Расширение G9: карта культурно-исторического контента

**Расширение G9 (решение владельца):** проект целиком связан с казахской культурой и историей —
приложение учит английскому и параллельно знакомит с историей страны. Поэтому G9 — не только
области и Абай, а **карта культурно-исторического контента**. В тот же файл добавь Часть 3:

**Часть 3 — карта тем (по 3–6 пунктов в каждой, у каждого 1–2 надёжных открытых источника):**
1. Древняя история: саки, тюркские каганаты, памятники (петроглифы Тамгалы, курганы — проверь статус ЮНЕСКО по сайту ЮНЕСКО).
2. Казахское ханство и великие личности (ханы, бии, батыры) — даты и факты только из источников.
3. Мыслители и поэты: Абай, а также другие классики, чьи тексты свободны от авторских прав (срок охраны проверь).
4. Традиции и быт: юрта, ою-өрнек, домбыра и кюй, тойы и обычаи, кухня, ремёсла.
5. Природа и места: заповедники, горы, озёра, святые места — со связью с легендами из Части 1.
6. Мақал-мәтел и бата (в приложении уже есть мақалы — посмотри src/data/culture.ts, не дублируй).
Для каждой темы: о чём (своими словами), почему интересно подростку и взрослому новичку, уровень
сложности для текста (A1–C1), источники, есть ли в приложении уже что-то по теме.
**Спорные исторические темы** (если встретятся) — отметь «спорная», дай источники разных сторон, без оценок.
Порядок: G8 → правки G6 → G9 (части 1–3). Объём большой — сдавай по частям (сначала Часть 1), wip-пушами.
