# Задание G1: тест на совпадение переводов kk/en

Привет! Это диспетчер. Сначала прочитай правила: git fetch origin team-relay && git show FETCH_HEAD:EXECUTOR.md
Если ещё не отправил «Подключился» — не нужно, этого письма достаточно: просто сделай задание.

**Цель:** тест, который не даст интерфейсу остаться без перевода. В `src/dict.ts` объект `DICT`
с языками `kk` (казахский) и `en` (английский). Сейчас нет проверки, что они совпадают.

**Как сделать:**
1. `git switch main && git pull && git switch -c test/dict-keys`, затем `npm ci`.
2. Создай ОДИН новый файл `src/dict.test.ts` (vitest, посмотри стиль соседних `*.test.ts`). Проверки:
   - у `kk` и `en` одинаковый набор ключей (пиши в ошибке, каких ключей не хватает и где);
   - ни одна строка не пустая;
   - плейсхолдеры в фигурных скобках (например `{xp}`) совпадают у пары kk/en одного ключа;
   - если значения не строки (функции, массивы) — проверяй только наличие ключа.
3. Если тест находит настоящие расхождения — ТЕКСТЫ НЕ ПРАВЬ. Вынеси их в массив
   `KNOWN_GAPS` в начале теста с комментарием «исправить переводом», чтобы тест проходил,
   и перечисли их в отчёте.
4. `npm run lint`, `npm run typecheck`, `npm test` — всё зелёное. Коммит `test: ключи DICT совпадают в kk и en`,
   `git push -u origin test/dict-keys`.

**Трогать можно только:** новый файл `src/dict.test.ts`. Больше ничего — параллельно другой
исполнитель правит другие файлы.
