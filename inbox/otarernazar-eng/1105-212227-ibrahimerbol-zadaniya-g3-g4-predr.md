# Задания G3–G4: предрегистрация OSF; новые источники по культурной знакомости

**Очередь:** это Задание G3. Делай после G2. Задания бери строго по номерам, одно за другим,
каждое — своя ветка от свежего main (main обновился: слиты #71 и #72).

**Задание G3: черновик предрегистрации на OSF.** Ветка `docs/osf-prereg-draft`,
один новый файл `docs/research-design/osf-prereg-draft.md`.
1. Найди и открой официальный шаблон OSF Preregistration (osf.io, Center for Open Science) —
   возьми его разделы как структуру документа, ссылку на шаблон укажи.
2. Заполни разделы ТОЛЬКО из файлов проекта: `docs/research-design/study-design.md`,
   `data-pipeline.md`, `ethics-consent-package.md`, `test-items-review.md`, `literature-review.md`,
   `docs/research-evidence.md`. Рядом с каждым утверждением — из какого файла взято.
3. Чего в файлах нет или что ещё не решено (число целевых слов 20/25, размер выборки, уровень,
   локализация данных, опрос мотивации и т.д.) — пиши `РЕШЕНИЕ РУКОВОДИТЕЛЯ: …` и не заполняй.
   Никаких выдуманных чисел, эффектов, мощности, дат.
4. В начале — пометка «ЧЕРНОВИК, не подан» и список открытых решений.
**Вернуть:** ссылку compare + список РЕШЕНИЙ РУКОВОДИТЕЛЯ.

**Задание G4 (после G3): новые источники по культурной знакомости текста и лексике.**
Ветка `docs/literature-additions`, один новый файл `docs/research-design/literature-additions-draft.md`.
Сначала прочитай `docs/research-design/literature-review.md` и `docs/research-evidence.md` — что
уже есть, не повторяй (там уже Pulido 2004, Klassen 2020, Erten & Razı и др.).
Найди 5–8 НОВЫХ исследований: культурно знакомый контент / schema theory и усвоение лексики или
понимание при чтении на L2, лучше подростки и школьники, лучше 2015+. Для каждого — только из
открытой страницы: полная ссылка с DOI, выборка (кто, сколько), дизайн, главный результат своими
словами, ограничения, чем полезно Ertegi. Не нашёл полный текст — помечай «только аннотация».
Не нашёл 5 — пиши сколько нашёл, не добирай сомнительным.
**Вернуть:** ссылку compare + 2–3 строки: что меняется в наших гипотезах.
