# ПРИОРИТЕТ G8: слепой арбитраж 174 спорных переводов A1 со ссылками

**ПРИОРИТЕТ от владельца — G8 делай сразу после текущего G6 (или прямо сейчас, если G6 сдан).**

**Задание G8: арбитраж 174 спорных переводов A1 — вслепую и с доказательствами.**
Во вложении `a1-arbitration-input.csv`: слово, часть речи, два варианта перевода (kk_v1/kk_v2, ru_v1/ru_v2).
Кто автор какого варианта — неизвестно и неважно (порядок перемешан). Оцени ТОЛЬКО по словарям.

Для каждой строки выбери отдельно для kk и для ru:
- `v1` / `v2` — верен один вариант;
- `both` — оба верны (тогда что показывать новичку A1 — укажи в `kk_final`/`ru_final`);
- `other` — оба неточны, твой вариант в `kk_final`/`ru_final`;
- `human` — нет надёжного источника или значение зависит от контекста (родство, служебные слова и т.п.).

Правила:
1. Решение `v1`/`v2`/`both`/`other` — только со ссылкой на открытую страницу (Wiktionary / Kaikki / Wikidata
   Lexemes / иной открытый словарь), где этот перевод есть для этой части речи. Нет ссылки — `human`.
2. Учитывай часть речи и уровень A1 (самое частое значение для новичка).
3. Служебные слова и формы (a, the, am, is, are, 's, to…) — почти всегда `human`, если словарь не даёт прямого соответствия.
4. Не спеши: лучше 60 честных `human`, чем 0 и выдуманные ссылки. Диспетчер выборочно откроет твои ссылки.

Выход: ветка `data/wordbank-a1-arbitration` от свежего main, один файл
`research/wordbank-translations/a1-arbitration.csv` с колонками:
id, headword, pos, kk_choice, kk_final, ru_choice, ru_final, source_url, comment.
`kk_final`/`ru_final` заполняй для всех, кроме `human` (для v1/v2 — скопируй выбранный вариант).
**Вернуть:** ссылку compare + сколько v1/v2/both/other/human по kk и по ru. В конце — «Урок:»/«Сработало:».
