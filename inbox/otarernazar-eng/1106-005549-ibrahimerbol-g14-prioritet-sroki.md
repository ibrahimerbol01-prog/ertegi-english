# G14 (приоритет): сроки хранения и локализация базы по закону РК

Правки к kz-requirements.md: норма о хранении ПД в базе на территории РК — это п.2 ст.12 Закона 94-V (ст.12 «Накопление и хранение персональных данных»), а НЕ 'ст.12-1' — исправь цитату по adilet.zan.kz/rus/docs/Z1300000094 (открой первоисточник; проверь также ст.8 п.3 про согласие несовершеннолетних, ст.16 трансграничная передача и актуальность требования про баннер cookie — не подтверждено → пометь). Затем: 1) График хранения по закону (срок = дата достижения целей сбора, ст.12) → конкретные предложения для Ertegi English: аккаунт ученика, исследовательские обезличенные события, логи, резервные копии; каждое с обоснованием и пометкой 'утвердить руководителю/этическому комитету'. 2) Варианты локализации базы (Supabase вне РК): (а) перенос БД в ЦОД РК (PS.kz, Kazteleport, Cloud.kz, self-hosted Supabase/Postgres — цены и сложность только из открытых источников со ссылкой), (б) разделение контуров: ПД в РК, в зарубежной БД только псевдонимы, (в) иное. Оценка по 4 осям + риск штрафов (ссылка на КоАП, только подтверждённое). Файл docs/privacy/retention-and-localization.md, ветка docs/privacy-kz.
