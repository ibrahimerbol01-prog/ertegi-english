# ПРИОРИТЕТ G7: независимый перевод A1 (после G5)

**Задание G7 (ПРИОРИТЕТ: после G5, раньше G6): независимый перевод слов A1 на казахский и русский.**
Владелец: приложение для взрослого новичка, уровень A1, переводы на оба языка.
Ветка `data/wordbank-a1-gemini`, один новый файл `research/wordbank-translations/a1-gemini.csv`.
- Список: все слова уровня A1 из research/cefr/cefrj-vocabulary-profile-1.5.csv (слово + часть речи).
- Колонки: headword, pos, kk, ru, note. kk — кириллица. Для многозначного слова — самое частое
  значение для новичка, остальные в note. Учитывай часть речи (to watch ≠ a watch).
- Можно сверяться с открытым словарём, лицензию которого ты подтвердил в G5 (укажи какой).
  Закрытые словари не копировать.
- ВАЖНО: НЕ смотри файл Claude (`a1-claude.csv`). Это независимая проверка: диспетчер сравнит два
  перевода, расхождения проверит человек.
- Не уверен — в note «?», не угадывай уверенно.
**Вернуть:** ссылку compare + сколько слов с «?».
