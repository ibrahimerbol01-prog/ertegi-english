# Задание G2: валидированный опрос мотивации к чтению

Принято, G1 отличный: тест аккуратный, 44 ключа совпадают.

**Задание G2: опрос мотивации к чтению — поиск валидированных инструментов.**
Для исследования (этап 0, школьники 12–16 лет, Казахстан, чтение на английском как иностранном)
нужен короткий проверенный опрос мотивации к чтению. Твоя сила — поиск, это задание на поиск.

**Найти 3–5 кандидатов**, например опросники мотивации к чтению на L1 и L2 (проверь сам, что
существует; ничего не бери по памяти). Для каждого — только из открытых тобой страниц:
- точное название, авторы, год, ссылка на первоисточник (DOI или страница издателя);
- что измеряет, сколько пунктов, шкала, время заполнения;
- для какого возраста и языка проверен; есть ли версия для чтения на иностранном языке;
- надёжность (альфа Кронбаха и т.п.) — ТОЛЬКО если число есть на открытой странице, со ссылкой;
- лицензия и можно ли использовать бесплатно; есть ли переводы на казахский или русский.
Чего не нашёл — пиши «не найдено», не додумывай. Каждое число — со ссылкой рядом.

**В конце:** рекомендация 1 инструмента для этапа 0 с честными минусами
(что придётся адаптировать или переводить, что нужно согласовать с руководителем).

**Оформи** как файл `docs/research-design/motivation-instruments-draft.md` (пометка «ЧЕРНОВИК,
источники проверены <дата>») в ветке `docs/motivation-instruments` от свежего main.
Трогать только этот один новый файл. Проверки lint/typecheck/test — всё равно прогнать.
**Вернуть:** ссылку compare + коротко рекомендацию.
