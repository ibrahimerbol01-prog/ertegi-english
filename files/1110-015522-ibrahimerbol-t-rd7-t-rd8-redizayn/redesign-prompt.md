Скопируйте всё ниже линии в новый чат с Claude Fable 5.2 (или Opus 5.5), в котором подключён репозиторий `ibrahimerbol01-prog/ertegi-english`.

Ты — старший фронтенд-инженер и дизайнер продукта. Внедри редизайн «Шаңырақ 2.0» в репозиторий `ibrahimerbol01-prog/ertegi-english`. Работай точно по этому документу. Если что-то в коде не совпадает с описанием, остановись на этом пункте, опиши расхождение и предложи решение, а не угадывай.

## 0. Контекст

- Ertegi English — веб-приложение (PWA, Vite + React + TypeScript + Tailwind 4, Supabase): казахские народные сказки на английском для школьников 10–17 лет, уровни A1–C1. Ридер с переводом по нажатию на слово, озвучка, проверка произношения, тесты, повторение слов, ИИ-помощник «Шоқан», кабинет учителя с классом по коду. Интерфейс на казахском (`kk`) и английском (`en`).
- Главная цель проекта — научно подтверждённая эффективность. Поэтому: никаких выдуманных цифр, отзывов, результатов в интерфейсе; данные исследования не ломать.
- Макеты: https://claude.ai/artifact/91WA4y8uWEfR8QGTZtEdbL (если не открывается, всё нужное описано ниже).
- Аудит, на котором основан редизайн: `docs/design-audit-2026-11.md` (добавь его в репозиторий в этапе 1 из приложенного файла, если владелец его дал).

## 1. Жёсткие правила (нарушение = остановиться)

1. Один этап = одна ветка `redesign/<номер>-<кратко>` от свежего `main` = один PR. PR не мержить: мержит владелец.
2. После каждого этапа зелёные: `npm run lint`, `npm test`, `npm run build`, а также `VITE_RESEARCH_MODE=1 npm run build`. Если тест падает из-за изменения разметки, обнови тест так, чтобы он проверял то же поведение; удалять тест без замены нельзя.
3. Все строки интерфейса только через `src/dict.ts` (kk и en). Тест паритета `src/dict.test.ts` должен проходить. Казахский текст бери из этого документа дословно; новых казахских формулировок не сочиняй — если нужна строка, которой здесь нет, поставь английскую и пометь в PR «нужен перевод владельца».
4. Hex-цвета в компонентах запрещены, только токены из `src/index.css` (`@theme`). Тени только через `--elev-*`.
5. Не трогать: `api/`, `supabase/`, `vercel.json`, `.github/`, зависимости (`package.json`, lock), тексты сказок и словарь переводов (`src/constants.ts`, `src/data/`), логику исследования (`src/research/`, журнал `learning_events`), кроме мест, явно названных ниже.
6. Исследовательская сборка (`VITE_RESEARCH_MODE=1`, алиасы `.off` в `vite.config.ts`): не добавлять в неё новых экранов и функций. Изменения ридера и теста попадают в неё автоматически — это разрешено только в этапах 4 и 5 и должно быть перечислено в описании PR отдельным разделом «Влияние на исследование».
7. Доступность: каждая касаемая цель ≥ 44×44 px (основные кнопки 56), текст ≥ 13 px (подписи нижней навигации 12 px — единственное исключение), контраст ≥ 4.5:1, настоящие `<button>`/`<a>`, `aria-label` у кнопок-иконок, видимый фокус, `prefers-reduced-motion` отключает анимации.
8. Без тёмной темы. Без новых шрифтов (Nunito и Inter уже лежат в `public/fonts`).
9. Не добавлять эмодзи в интерфейс. Иконки — существующие из `src/components/Icons.tsx` или inline SVG в том же стиле (stroke 2, скругления).
