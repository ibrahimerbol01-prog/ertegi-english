Краткое содержание:
- Первоисточники: Закон РК № 94-V «О персональных данных и их защите» (https://adilet.zan.kz/rus/docs/Z1300000094), ГК РК ст. 22, 23 (дееспособность), Закон «О правах ребенка в РК», Приказ МЦРИАП РК № 395/НҚ.
- Обязательные разделы политики: оператор, цели сбора, перечень ПД, сроки, права субъекта, порядок отзыва согласия и уничтожения.
- Несовершеннолетние: дети до 14 лет — согласие дают исключительно законные представители (ст. 23 ГК РК, ст. 8 п. 3 Закона о ПД); 14–18 лет — с согласия родителей (ст. 22 ГК РК). Необходима форма Parental Consent.
- Локализация (ст. 12-1): база данных граждан РК обязана физически располагаться в ЦОД на территории РК (предложено архитектурное разделение: ПД в РК, в глобальный контур уходят только обезличенные токены UUID).
- Cookie и аналитика: обязательный баннер информирования и выбора, отказ от рекламных трекеров при работе со школьниками.
- Этические комитеты (IRB): обязательность связки «Parental Consent + Child Assent», строгая псевдонимизация (коды участников вместо ФИО), право прекратить участие без академических санкций.
- Везде выставлены пометки «проверить юристом».

Проверки:
- npm run lint: 0 warnings, 0 errors
- npm run typecheck: tsc -b успешно

Урок: Статья 12-1 Закона РК накладывает жесткое требование к физическому размещению первичной базы данных в Казахстане, что критично учитывать при выборе инфраструктуры (Firebase/Supabase vs локальный ЦОД).
Сработало: Точное сопоставление возрастных градаций Закона о ПД со статьями 22 и 23 Гражданского кодекса РК сняло правовую неопределенность по детям 14-18 лет.
