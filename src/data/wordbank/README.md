# Wordbank «Сөздік қоры» data

Generated by `npm run wordbank` (scripts/wordbank-build.mjs) from the sources in `config.ts`. Do not edit the JSON by hand.

- `A1.json` … `B2.json`: from The CEFR-J Wordlist Version 1.5, compiled by Yukio Tono, Tokyo University of Foreign Studies (free for research and commercial use with citation).
- `C1.json`, `C2.json`: from Octanove Vocabulary Profile C1/C2 (ver. 1.0), Octanove Labs, licensed CC BY-SA 4.0. These two derived files are shared under the same licence, CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
- `example`: a sentence of our own tales (src/constants.ts) where the word occurs, with the tale id, the level and the form as written. Matched by spelling; an inflected form only for the entry's own part of speech. The exact spelling cannot tell parts of speech apart (the noun "watch" may show "Watch me").
- `kk`, `ru`: empty until a reviewed translation task fills them.
- Left out until the delayed test of the study: the target words in `EXCLUDED_UNTIL_DELAYED_TEST` (config.ts).

Sources as copied in the repo: research/cefr/README.md.
