# Плавность: аудит анимаций (BACKLOG «Плавность и скорость», п. 1)

Дата: 06.11.2026. Источник: `src/index.css` (скрипт по `@keyframes` и `transition`), использование классов в `src/**/*.tsx`.

## Замер

| Проверка | Результат |
|---|---|
| Анимации (`@keyframes`) только на transform/opacity | **12 из 12** (pop-in, sheet-up, bob, float-slow, spin-slow, card-shine, xp-float, confetti-fall, rank-pop, answer-correct, answer-wrong, achievement-slide) |
| `prefers-reduced-motion` | уже есть глобально (`index.css`, строка 240): длительность анимаций и переходов → 0,01 мс, без повторов |
| Переходы на свойствах раскладки | **1**: `.track > span { transition: width 0.5s }` — полоса прогресса (QuizScreens:350, WordsScreens:139, :303, SpeakScreen:283) |
| CLS главной (Lighthouse, медиана) | 0–0,002 |
| Длительность анимаций | 0,32–0,55 с для появления/ответа; бесконечные (bob, float, twinkle, card-shine) — только декоративные |

## Решение

**Не брать** новые анимации и переделку полосы прогресса сейчас:
- Полоса прогресса — единственное место на `width`. Перевод на `transform: scaleX` даст выигрыш, который не измерить (CLS уже ≈ 0, полоса узкая), а полоса стоит в квизе исследовательской сборки — правка изменила бы её код.
- Новые анимации (переходы между экранами, View Transitions) по оценке BACKLOG: научная ценность нет, образовательная средняя, риск для исследования есть — нужен флаг. Измеримой пользы без пользовательских данных не показать.

**Взять позже, если владелец решит:** полоса на `scaleX` только в обычной сборке (alias/флаг) вместе с другими правками экранов, чтобы не плодить отдельный PR ради одной строки.

| Ось | Новые анимации | Полоса на scaleX |
|---|---|---|
| Научная | нет | нет |
| Образовательная | средняя (гипотеза) | нет |
| Сложность | средняя | низкая |
| Исследование | риск, нужен флаг + тест | меняет общий код квиза |
