# Аудит главной (заставка «Дала аңыздары ағылшын тілінде») — Задание 13

Дата: 06.11.2026. Код: `src/components/IntroScreen.tsx`, `src/App.tsx`, main 7e23042. Замеры: сборка `vite preview`, встроенный браузер (Chromium), скрипт контраста по WCAG 2.1 (относительная яркость).

## 1. Исследовательская сборка

Заставка показывается **в обеих сборках**, до входа и до согласия (`App.tsx`: `if (!introSeen) return <IntroScreen …/>`, условия на `RESEARCH_MODE` нет). Значит, любая правка заставки меняет и исследовательский сайт. Решение: новая заставка — отдельный компонент, выбор в `App.tsx` по `RESEARCH_MODE` (на исследовательском сайте остаётся текущий `IntroScreen` без изменений) + тест.

## 3. Проблемы и предлагаемые правки (оценка по 4 осям)

| # | Проблема | Правка | Научная | Образовательная | Сложность | Исследование |
|---|---|---|---|---|---|---|
| 1 | На 360×640 главной кнопки не видно | На низких экранах уменьшить иллюстрацию (220 → 140 px при высоте < 700) | нет | низкая (меньше трения на старте) | низкая | только вне исследовательской сборки |
| 2 | «Өткізіп жіберу» делает **то же, что «Бастау»** (оба `onFinish`) — две кнопки с одним действием, мелкий текст | Заменить на вторичную кнопку с понятным действием: «Аккаунтым бар — кіру» (открывает форму входа, а не регистрации) | нет | низкая | низкая (AuthScreen принимает начальный режим) | вне исследовательской сборки |
| 3 | Абстрактный значок, не видно, что внутри | Карточка одной сказки: обложка (`StoryCover`), название, «5 деңгей: A1–C1» — всё это правда о контенте | нет | средняя (сразу видно, что учит приложение) | низкая | вне исследовательской сборки |
| 4 | Нет строки «что дальше» | Под кнопкой: «Келесі қадам: тіркелу немесе кіру» — только то, что произойдёт. Без «бесплатно» и других обещаний, которых в коде не видно | нет | низкая | низкая | вне исследовательской сборки |
| 5 | Нет переключателя языка | kk / en, как в AuthScreen (`saveLang`). **ru** в интерфейсе нет совсем (DICT только kk и en) — это отдельная задача на весь DICT, не правка заставки | нет | средняя (понятный язык с первого экрана) | низкая для kk/en | вне исследовательской сборки |

## Аудит по ролям

- Исследователь: заставка общая для обеих сборок — без флага любая правка поменяла бы условия исследования. Учтено.
- UX: главная проблема — невидимая кнопка на маленьком телефоне и две кнопки с одним действием. Обе исправимы без нового дизайна.
- EdTech: превью сказки показывает суть продукта — чтение по уровням — лучше абстрактного значка.
- Консультант: строка «что дальше» без маркетинговых обещаний: только то, что правда.
