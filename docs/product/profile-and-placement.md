## (А) Ник и аватар

**Предложение.** Ник: правка `display_name` в профиле — 1–30 символов после `cleanNick`, только буквы (кириллица/латиница), цифры, пробел, дефис; короткий стоп-список слов — **[УТОЧНИТЬ у владельца: чей список и на каких языках]**; уникальность не нужна. Ник в классе не меняется автоматически (он отдельный, учитель его уже знает). Аватар: выбор из **наших** иллюстраций — 3 орнамента (Қошқар мүйіз, Шаңырақ, Тұмар из `Ornaments.tsx`) × 5 цветов палитры + 7 обложек сказок (`StoryCover`) ≈ 22 варианта; хранится только id варианта. **Без загрузки фото.**

SQL (не применять):
```sql
alter table public.profiles add column avatar text
  check (avatar is null or avatar ~ '^(orn-(qoshqar|shanyraq|tumar)-(sky|jade|sun|felt|night)|tale-[a-z_]+)$');
alter table public.profiles add constraint profiles_display_name_len
  check (display_name is null or char_length(btrim(display_name)) between 1 and 30);
-- RLS: правка своей строки profiles уже разрешена (update own row); delete_my_account удаляет profiles целиком.
```

| Ось | Оценка |
|---|---|
| Научная ценность | нет |
| Образовательная | низкая–средняя: «свой» профиль может поддерживать вовлечённость — гипотеза, не доказано |
| Сложность | низкая: 1 колонка, экран выбора, валидация, тесты |
| Влияние на исследование | нет, если редактор **выключен** в исследовательской сборке (alias на заглушку, как `WordbankScreen.off`), + тест. Новых ПД нет: id аватара не ПД, имя уже хранится |

## (Б) Входной тест уровня

**Предложение v1.** Фиксированный короткий тест на 20 пунктов, после регистрации, его можно пропустить и пересдать из профиля:
- 15 пунктов «знаешь ли это слово? да/нет» по 3 слова A1, A2, B1, B2, C1 из наших списков CEFR-J/Octanove, плюс 5 псевдослов против угадывания (как в формате recognition исследовательского теста);
- **все целевые слова исследования исключены** (`EXCLUDED_UNTIL_DELAYED_TEST`) — иначе тест на обычном сайте тренировал бы их до отсроченного теста;
- псевдослова — свои, «на проверку учителю»; для A1 можно добавить 3–5 пунктов «значение» с проверенными переводами (tr=human/agreed).

Итог — **оценка**: «примерно A2», не диагноз. Рекомендация: уровень текста сказки, с которого начать, и число слов в день. Ничего не блокирует. Правило перевода баллов в уровень — **гипотеза**, которую надо проверить (сравнить с оценкой учителя на апробации). Ссылок на валидацию yes/no-тестов я здесь не даю: источники надо найти и прочитать (задача для Gemini, research-ops).

Хранение v1: только на устройстве (localStorage) + выбранный уровень в интерфейсе. **Без событий журнала** и без новой таблицы: так нет новых ПД и миграции. В v2 — `learner_state` kind `placement` (нужна миграция check-ограничения kind и `KINDS`).

| Ось | Оценка |
|---|---|
| Научная ценность | низкая–средняя: оценка не валидирована. Ценность появится, если сравнить с учителем (гипотеза) |
| Образовательная | средняя–высокая: новичок (в том числе взрослый, A1) сразу получает подходящий уровень текста вместо выбора наугад |
| Сложность | средняя: новый экран, банк пунктов из словаря, правило оценки, тесты. Движок исследовательского теста напрямую не переиспользовать: он живёт в `src/research` и выключен в обычной сборке; брать только идеи форматов |
| Влияние на исследование | нет, если: (1) экран выключен в исследовательской сборке (alias + тест, как словарь); (2) целевые слова исключены (тест); (3) другие глаголы событий / без событий, чтобы не путать с `test_answer` |

**Вердикт: взять**, вторым PR после (А), v1 без событий и без миграции.

## Защита исследования (для обоих)

- `ProfileEditor` и `PlacementTest` — ленивые экраны; в `vite.config.ts` для исследовательской сборки alias на `*.off.tsx` (пустая заглушка), как `WordbankScreen`.
- Тесты: в исследовательской сборке кнопок нет (рендер с `RESEARCH_MODE: true`); экранов нет в бандле (проверка сборкой `VITE_RESEARCH_MODE=1` и поиском строк); целевые слова исключены из банка пунктов.

## Аудит по ролям (что слабо)

- Исследователь: правило «баллы → уровень» без валидации — помечено как гипотеза, в интерфейсе пишется «примерно».
- UX: тест сразу после регистрации может отпугнуть — поэтому кнопка «Пропустить» видна сразу, пересдать можно в профиле.
- EdTech: 15 пунктов на 5 уровней дают грубую оценку; для v1 этого хватает, точнее — адаптивный тест в v2.
- Консультант: аватары из своих иллюстраций без фото — нет модерации и юридических рисков с детскими фото.
