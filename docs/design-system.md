# Ertegi design system

Казахский этно-стиль: степная ночь, войлок (киіз), золото и орнамент. Орнамент работает как акцент, а не как заливка.

## Цвета (`src/index.css`, `@theme`)

| Токен | Hex | Где |
|---|---|---|
| `ink` | #0B2128 | фон страницы |
| `ink-2` | #0F2C35 | модалки, сайдбар, нижняя навигация |
| `surface` | #133640 | карточки, поля, чипы |
| `surface-2` | #1A4450 | hover |
| `line` | #2A5662 | треки, тонкие линии |
| `cream` | #F6EEDC | основной текст |
| `gold` / `gold-deep` | #E7A93F / #B97A1F | главный акцент, кнопки, активная навигация |
| `felt` / `felt-deep` | #C8502E / #8F3119 | вторичные метки, ошибки, кромка шапки |
| `turq` | #4DBFAE | успех, правильный ответ |

В компонентах использовать классы `bg-ink`, `text-gold/70` и т.д., не hex.

## Шрифты

- Заголовки: Alegreya SC (`.font-editorial`), сказочные капители.
- Текст: Manrope (`.font-body`).
- Оба поддерживают латиницу казахского (ä ğ ı ñ ö ş ū ü) и кириллицу (Ә Қ Ң Ө Ұ Ү Һ І).
- Минимальный кегль: 10px.

## Орнаменты (`src/components/Ornaments.tsx`)

Все SVG рисуются `currentColor`, цвет задаётся `text-*`.

| Компонент | Мотив | Где использовать |
|---|---|---|
| `QoshqarMuyiz` | қошқар мүйіз | маркер у заголовков (через `KazakhOrnament`) |
| `Shanyraq` | шаңырақ | логотип, медальоны (уровень, диплом, вход) |
| `Tumar` | тұмар | маркер разделов, разделитель «или» |
| `OrnamentBand` | бордюр из рогов | верх/низ вступления, низ сайдбара |
| `OrnamentDivider` | линия с рогами | под заголовком вступления |
| `OrnamentFrame` | уголки | главные карточки и модалки, не больше одной рамки на экран |
| `SteppeBackground` | фон с решёткой рогов, 4.5% | фон приложения и входа |
| `.ornament-rule` | CSS-бордюр | нижняя граница заголовка экрана |

Правило меры: на экране максимум один крупный орнамент (рамка или водяной знак) плюс мелкие маркеры.

## Компонентные классы (`FontLoader` в `UIHelpers.tsx`)

`glass-luxury-card` (карточка), `glass-card-hover`, `gold-badge`, `terracotta-badge`, `gold-glow`, `ornament-rule`. Фокус: золотой outline 2px. `prefers-reduced-motion` отключает анимации.
