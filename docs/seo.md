# Как сайт находят в поиске

Дата: 11.11.2026. Код: `vite-seo.ts` (подключён в `vite.config.ts`), тест `src/research/seo.test.ts`.

## Что делает сборка

Обычный сайт: заголовок и описание по-казахски и по-английски, `canonical`, Open Graph и Twitter-карточка (картинка `story-poster.jpg`), структурированные данные JSON-LD (`WebApplication`, образовательное приложение), текст для роботов без JavaScript (`<noscript>`), `sitemap.xml` и `robots.txt` со ссылкой на него (`/api/` закрыт).

Сайт исследования (`VITE_RESEARCH_MODE=1`): `noindex, nofollow, noarchive` в странице и `Disallow: /` в `robots.txt`, карты сайта нет. Дети на нём работают по кодам, поиск его видеть не должен. Тест проверяет это.

Переменные сборки (Vercel → Settings → Environment Variables, проект `ertegi-english`):
- `VITE_SITE_URL`: адрес сайта без слеша в конце. По умолчанию `https://ertegi-english.vercel.app`; при своём домене поменять здесь, и `canonical`, `sitemap.xml` и `robots.txt` обновятся сами.
- `VITE_GOOGLE_SITE_VERIFICATION`, `VITE_YANDEX_VERIFICATION`, `VITE_BING_VERIFICATION`: значения тегов подтверждения (необязательно, если подтверждаешь другим способом).

## Что нужно сделать владельцу (код этого не заменит)

Новый сайт не появляется в поиске сам: пока поисковик о нём не знает, его не найти даже по точному названию.

1. **Google Search Console** (search.google.com/search-console): «Добавить ресурс» → «Префикс URL» → `https://ertegi-english.vercel.app/`. Подтвердить владение: способ «HTML-тег», взять значение из `content="..."`, положить в Vercel как `VITE_GOOGLE_SITE_VERIFICATION`, сделать Redeploy, нажать «Подтвердить».
2. Там же: «Файлы Sitemap» → ввести `sitemap.xml` → «Отправить». Потом «Проверка URL» → адрес главной → «Запросить индексирование».
3. **Яндекс Вебмастер** (webmaster.yandex.kz): то же самое с `VITE_YANDEX_VERIFICATION`. В Казахстане им много пользуются, поэтому не пропускать.
4. По желанию **Bing Webmaster Tools** (с него можно импортировать сайт из Google).
5. **Свой домен.** Адрес на `vercel.app` ищется хуже и выглядит несерьёзно для школ и акимата. Купить домен (`.kz` продаёт аккредитованный регистратор, цену и правила смотреть у него), подключить в Vercel → Domains, прописать `VITE_SITE_URL`, в Supabase добавить новый адрес в Redirect URLs, в Search Console добавить новый ресурс.
6. **Ссылки на сайт**: страница в Instagram, статья про РКНП на сайте школы или акимата, GitHub-репозиторий (в описании ссылка на сайт). Чем больше честных ссылок, тем быстрее индексация.

## Чего ждать

Первая индексация занимает от нескольких дней до нескольких недель, ускорить её нельзя, только запрос индексирования помогает. Позиции по общим запросам («английский язык для детей») зависят от конкуренции; по названию «Ertegi English» сайт должен находиться первым после индексации. Гарантий по срокам нет.

## Ограничения

- Приложение рисуется скриптом (React), у сайта фактически одна страница: индексироваться будет в основном главная. Больше страниц для поиска (описания сказок, статьи) нужны отдельными страницами: это новая функция, её нужно оценить отдельно (научной ценности нет, образовательная и стартап-ценность средняя, сложность средняя).
- Сказки и задания закрыты входом: роботы их не увидят, и это нормально для учебной платформы с детьми.
