## 0. Коротко

| Вопрос | Ответ |

| Рекомендуемый дизайн этапа 1 | **Внутрисубъектный, по парам текстов.** Для каждой из 5 сказок есть пара: фольклорный текст F и контрольный текст C с незнакомым культурным содержанием и с **теми же** целевыми словами. | Главное решение до 31.12.2026 | Целевые слова, правило для квиза и SRS (раздел 3.1), возможность загрузить контрольные тексты как контент после заморозки сборки. |

## 1. Гипотезы и меры

### 1.1 Гипотезы

| № | Гипотеза | Мера | Статус |
|---|---|---|---|
| **H1** | Целевое слово, прочитанное во фольклорном тексте, ученик знает на **отсроченном** тесте (через 3–4 недели после последнего текста) с большей вероятностью, чем то же слово, прочитанное в контрольном тексте, при учёте знания этого слова на претесте. | Пункт «значение» (выбор казахского перевода), 0/1 на каждую пару «ученик × слово» | **Основная**, подтверждающая |
| H2 | То же на **немедленном** тесте (неделя после блока чтения). | Тот же пункт, немедленный тест | Дополнительная |
| H3a | Понимание фольклорного текста выше, чем контрольного. Ожидание основано на работах о понимании: Johnson 1981, Erten & Razı 2009 (сверить). | 5 вопросов на понимание после каждого текста, доля верных | Дополнительная |
| H3b | Интерес и мотивация выше после фольклорного текста. | Оценка интереса к тексту по 1 пункту (1–5) после каждого текста. Опрос мотивации к чтению до и после (6–8 пунктов, адаптация MRQ, Wigfield & Guthrie 1997, сверить) | Дополнительная |
| E1–E3 | Процессы: число нажатий на целевое слово, время чтения, повторы аудио в F и C; зависит ли эффект от уровня ученика на претесте; зависит ли эффект от сказки. | Журнал событий | **Разведочные**, только описание |

Дополнительные гипотезы проверяются с поправкой Холма на 3 проверки (H2, H3a, H3b). Разведочные анализы не используются для вывода об эффекте.

### 2.4 Вывод о выборке и выбор дизайна

1. **Межгрупповой дизайн на 2–4 классах реалистичен только для крупного эффекта** (d ≈ 0,5 и больше, при r = 0,7 нужно около 70 анализируемых). Для d = 0,3–0,4 нужно 106–266 учеников, то есть 5–11 классов. Эффект на лексику у нас не измерен: Pulido 2004 не прочитана, d из Erten & Razı (0,81–1,61) относятся к **пониманию** у студентов и на n = 44. Закладываться на d ≥ 0,5 нельзя.
2. **Внутрисубъектный дизайн при 50–60 анализируемых даёт мощность 0,77–0,85 для OR 1,5 (d ≈ 0,34).** Для d ≈ 0,22 (OR 1,3) мощности не хватит ни в одном дизайне. Это нужно честно написать в предрегистрации как минимальный обнаружимый эффект.
3. Самое уязвимое допущение — **разница эффекта между сказками**. Пар всего 5, и если одна сказка сильно знакомее других, мощность падает до 0,61–0,75. Поэтому вывод формулируется о **пяти конкретных парах текстов**, а не о «фольклоре вообще».
4. **Минимум:** включить 3 класса, лучше 4, около 75–100 учеников, чтобы после отсева осталось ≥ 55. Если доступно только 2 класса, этап 1 честно называется пилотным с оценкой эффекта и доверительным интервалом, без подтверждающего вывода.

| | Межгрупповой (рандомизация внутри класса) | **Внутрисубъектный, по парам (рекомендуется)** |
|---|---|---|
| Мощность при N ≈ 55, OR 1,5 | ≈ 0,40 | ≈ 0,80 |

## 3. План анализа (внутрисубъектный дизайн)

### 3.1 Что должно быть одинаковым в F и C (решение до заморозки 31.12.2026)

- Длина, средняя длина предложения, MATTR, профиль CEFR-J, покрытие переводом, **число повторов каждого целевого слова** и примерно равное их распределение по тексту. Допуски в разделе 6.
- Озвучка тем же голосом. Жанр одинаковый: контрольный текст — **сказка далёкой культуры** (например, скандинавская или латиноамериканская), а не бытовой рассказ. Иначе вместе с культурой меняется жанр.
- Квиз после текста: одинаковые вопросы по целевым словам в F и C.
- **SRS для целевых слов выключен до отсроченного теста.** Если SRS будет повторять целевые слова 3–4 недели, отсроченный тест будет измерять SRS, а не текст, и разница между F и C сотрётся. Это компромисс с ценностью продукта, решение принимает руководитель. Вариант «SRS одинаковый в обоих условиях» допустим, но тогда мощность ниже расчётной, насколько — неизвестно.
- ИИ-помощник выключен (уже так). Пять сказок исследования закрыты в приложении до начала этапа 1. Если ученик уже читал их раньше, это видно по story_open, такой ученик отмечается.

### 3.2 Основная модель (задаётся заранее, предрегистрация на OSF)

Смешанная логистическая модель, R lme4::glmer (сверить версию). Единица — пара «ученик × слово».

```
known_delayed ~ folk + known_pre + position + form + pair
              + (1 + folk | student) + (1 | word) + (1 | class)
```

- `folk`: 1, если слово ученик читал в версии F. Оценка: OR с 95 % ДИ, плюс разница в процентных пунктах (средний предельный эффект).
- `pair` как фиксированный эффект с 5 уровнями: для случайного эффекта уровней слишком мало.
- Порядок упрощения, если модель не сходится, задаётся заранее: (1) убрать `(1|class)`, (2) убрать случайный наклон `folk|student`, (3) перейти на кластерно-устойчивые SE по ученику.
- Анализ чувствительности: (а) только слова, неизвестные на претесте; (б) суммарный балл по трём форматам; (в) анализ A из раздела 2.3 (парная разность по ученикам).

### 3.3 Выборки для анализа и пропуски

| Выборка | Определение | Роль |
|---|---|---|
| ITT (основная) | Все рандомизированные ученики с претестом и отсроченным тестом | Основной вывод |
| Per-protocol | Плюс прочитаны ≥ 4 из 5 текстов (level_complete) и ≥ 1 текст в каждом условии | Чувствительность |

- Пропуски отдельных пунктов теста (не ответил) кодируются как «не знает» только в чувствительном анализе. В основном анализе это пропуск: GLMM использует все наблюдения и корректен при MAR.
- Пропущен отсроченный тест целиком: ученик выпадает из ITT. Если таких > 15 %, проводится множественная импутация по претесту, немедленному тесту и процессным данным (20 наборов). Доли отсева в F и C сравниваются между собой, хотя внутрисубъектно они почти совпадают.
- Публикуется схема движения участников в стиле CONSORT.

### 3.4 Проверка манипуляции (до оценки H1)

| Проверка | Ожидание | Что делать, если не так |
|---|---|---|
| Знакомость сюжета (1–4), F против C | F выше, разница ≥ 1 балла по медиане | H1 интерпретируется как «нет манипуляции», а не «нет эффекта» |
| Трудность текста (1–5) | Разница F и C ≤ 0,5 балла | Отчёт с оговоркой. Трудность как ковариата в чувствительном анализе |
| Время чтения, нажатия на целевые слова | Описательно, без порога | Это механизм, а не помеха: в модель H1 не включается, потому что это переменная после воздействия |
| Целостность версии | Все события с ожидаемой contentVersion | Данные с чужой версией исключаются |

### 3.5 Критерии вывода (задаются заранее)

- **Наименьший интересный эффект (SESOI): +5 п. п.** на отсроченном тесте. Это **допущение**, его утверждает руководитель вместе с учителем.
- **H1 подтверждена**, если OR > 1 и 95 % ДИ не включает 1 в основной модели.
- **Практически нулевой эффект**, если 90 % ДИ для разницы в п. п. целиком внутри ±5 п. п. (TOST).
- **Неубедительно** во всех остальных случаях. Так и пишется в статье, без «тенденций».
- Направление, противоположное гипотезе, сообщается как есть.

### 4.2 Критерии успеха (пороги заданы заранее, это **предложения на утверждение**)

При n = 10–15 все оценки очень неточные (например, ДИ для α шириной около ±0,2). Поэтому пороги — это сигналы к действию, а не статистические проверки.

| Критерий | Порог успеха | Действие, если порог не пройден |
|---|---|---|
| Дошли до конца (все тесты + ≥ 3 текста) | ≥ 80 % включённых | Выяснить причины. Перенести чтение и тесты в урок. Для этапа 1 закладывать 60 % и включать 4 класса |
| Время в приложении | Медиана ≥ 15 мин в неделю (по событиям) | Чтение только в классе по расписанию. Проверить, не мешает ли длина текста B1 |
| Прошли все 4 тестовых сеанса | ≥ 85 % учеников | Сократить тест (вынести «употребление» в отдельный сеанс), проверить экран теста |
| Время теста | Медиана ≤ 25 мин, 90-й процентиль ≤ 35 мин | Убрать худшие пункты, разбить тест на 2 части |
| Надёжность, пункт «значение» (25 слов) | α и ω ≥ 0,70 (точечно, bootstrap-ДИ в отчёт) | Убрать или заменить пункты с корреляцией пункт–тест < 0,20, проверить дистракторы |
| Равенство форм A и B | Разница средних ≤ 10 п. п., корреляция A–B ≥ 0,60, у каждой пары пунктов разница p ≤ 0,25 | Поменять местами или переписать неравные пункты. Формы балансировать по трудности |
| Потолок и пол на претесте | Средняя доля известных слов 10–50 %; ни одно слово не знают > 70 % | Заменить слово из резерва (раздел 5.2). Если весь тест у потолка, перейти на уровень B2 |
| Полнота журнала | ≥ 98 % сессий с парой story_open → level_complete или явный выход; 0 событий без версии контента; потери outbox ≤ 2 % по сверке счётчиков устройства и сервера | Баг-фикс до этапа 1 (исправления ошибок при заморозке разрешены) |
| Манипуляция | Знакомость F > C у ≥ 80 % учеников | Пересмотреть выбор контрольных сказок или формулировку вопроса |
| Вопросы на понимание | Нет вопросов с p > 0,95 или p < 0,20 | Переписать вопрос |
| Нагрузка на учителя | ≤ 10 мин сверх урока на сеанс (по интервью) | Упростить сценарий, сделать готовый скрипт урока |

Итог этапа 0 — короткий отчёт о проверке осуществимости и решение «идём / идём с изменениями / откладываем» до предрегистрации.

## 5. Схема теста (blueprint)

### 5.1 Какой уровень взять

| Уровень | За | Против | Решение |
|---|---|---|---|
| A1 | Короткие тексты | Целевые слова — базовые A1 (bird, home, water): у 10–16-летних почти наверняка потолок | Нет |
| A2 | Подходит для 5–6 классов | Подходящих слов (уровень A2 и выше или вне списков, ≥ 2 повторов) 1–3 на сказку (`target_pool.py`) | Только если тексты переписать до 31.12 |
| **B1** | 297–343 слова, покрытие на уровне B1 0,92–0,98, перевод по нажатию закрывает 100 %; 3–5 подходящих слов на сказку | Ayaz bi труднее остальных: покрытие на B1 0,923, ниже порога 95 %, много реалий (khan, courtier, shapan) | **Да, для 7–9 классов (13–15 лет)** |
| B2–C1 | Больше слов высокого уровня | 426–728 слов, для 10–16 лет и 5 текстов длинно; у ayaz_bi покрытие на своём уровне ниже 95 % (0,944 и 0,94) | Нет, B2 — запасной вариант при потолке на претесте |

Уровень владения учеников не измерен. Пригодность B1 проверяется на этапе 0 по претесту и вопросам на понимание.

### 5.2 Отбор целевых слов: черновой список (уровень B1) — **на утверждение руководителю**

Правило черновика:
- содержательное слово уровня CEFR-J A2–B2 или общеанглийское слово вне списка (nest, courtier);
- не меньше 2 повторов в тексте B1;
- **не** казахская реалия (khan, steppe, batyr, zindan, shapan): в контрольном тексте её не может быть;
- не очевидный русский когнат (dragon ≈ «дракон»);
- не служебное слово (while, more, than).

Лемматизация в скрипте грубая, поэтому повторы нужно пересчитать через `npm run corpus`.

### 5.3 Формы A и B

- В обеих формах **одни и те же 25 слов**: это нужно, чтобы мерить прирост по каждому слову. Различаются дистракторы, предложения в пунктах «употребление», псевдослова и порядок пунктов.
- Пары пунктов A и B уравниваются по трудности на этапе 0.
- Последовательность форм контрбалансирована: половина учеников проходит A (претест) → B (немедленный) → A (отсроченный), половина B → A → B.
- Тексты сказок в пунктах не цитируются: предложения новые, чтобы не мерить узнавание фразы из текста.

### 5.4 Состав теста

| Часть | Формат | Пунктов | Время | Подсчёт |
|---|---|---|---|---|
| 1. Узнавание формы | Слово на экране и в аудио: «Встречал это слово?» Да / Нет. 25 целевых слов + 10 псевдослов | 35 | ≈ 3 мин | Попадания минус ложные тревоги на псевдословах; если ложных тревог > 30 %, ученик отмечается |
| 2. **Значение (основная мера)** | Выбор казахского перевода из 4 вариантов + «Не знаю» | 25 | ≈ 8 мин | 1 = верно, 0 = неверно или «не знаю» |
| 3. Употребление | Новое предложение с пропуском, 4 целевых слова на выбор | 25 | ≈ 10 мин | 1 / 0 |
| 4. Понимание | 5 вопросов после **каждого** прочитанного текста (в приложении, сразу после чтения; на претесте нет) | 5 × 5 | ≈ 4 мин на текст | Доля верных по тексту |

Общее время тестовой сессии около 21 минуты плюс инструкция, укладывается в урок. Подсказок, XP и перевода по нажатию на экране теста нет. Каждый ответ пишется с формой, моментом (pre/post/delayed), временем ответа и версией контента.

### 5.5 Примеры форматов (не из итогового теста)

1. **Значение.** *loyal* — а) адал б) ашулы в) сабырлы г) батыл д) Білмеймін. Дистракторы — казахские прилагательные той же части речи, частотности и тематики, черновик для проверки учителем казахского.
2. **Употребление.** *The thieves were locked in a ___ for ten years.* — pit / prison / chest / village. Ответ prison. Лишь один вариант подходит по смыслу; другие варианты — целевые слова той же части речи.
3. **Понимание** (контрольный текст, вопрос о сюжете, а не о слове). *Why did the girl leave the village?* — 3 варианта ответа. Вопрос не проверяет целевое слово, чтобы меры H1 и H3a не пересекались.

## 6. Риски и меры

| Риск | Чем грозит | Мера |
|---|---|---|
| Новизна приложения | Высокая вовлечённость в начале, спад к концу | Внутрисубъектно новизна одинакова для F и C. Порядок текстов случайный, позиция входит в модель. Динамика времени по неделям описывается отдельно |
| Эффект Хоторна | Ученики стараются, потому что участвуют | Действует на оба условия. Гипотезу ученикам не сообщаем: «мы изучаем, как школьники читают разные истории» |
| Разные учителя | Учитель с увлечением подаёт фольклор | Сравнение идёт внутри ученика, поэтому главный эффект учителя убирается. Единый скрипт урока. Учитель не видит, какая версия у какого ученика: названия текстов нейтральные. Класс — случайный эффект |
| Контрольные тексты неравны по сложности | Эффект знакомости смешивается со сложностью (Johnson 1981, сверить) | Допуски к каждой паре: длина ±10 %; средняя длина предложения ±1,5 слова; MATTR ±0,03; покрытие на B1 ±2 п. п. На этапе 0 сравниваются оценки трудности учениками |
| Казахские реалии (khan, steppe, batyr, shapan, aul, zindan) вне списков CEFR-J | Для казахского школьника это знакомые слова (хан, дала), а в C-тексте похожих облегчений нет | Реалии не берутся в целевые и не тестируются. В C-текст вставляется столько же культурных реалий его культуры (troll, fjord и т. п.), тоже с переводом по нажатию. Покрытие пары уравнивается по двум правилам: реалии неизвестны и реалии известны. Знакомые реалии сами по себе часть манипуляции «знакомость», в статье это оговаривается |
| Русские когнаты | Слова знают до чтения | Исключаются из целевых, контролируются претестом |
| Ученики уже читали сказки в приложении | Целевые слова встречались до претеста | 5 сказок закрыты в исследовательской сборке. Ранние story_open фиксируются, такие ученики идут в чувствительный анализ |
| SRS и квиз сглаживают разницу | Отсроченный тест мерит SRS, а не текст | Раздел 3.1: SRS для целевых слов выключен до отсроченного теста, квиз одинаковый |
| Заражение (обсуждение сюжетов) | Ученик с C-версией узнаёт сюжет F-версии | Чтение в классе одновременно, просьба не пересказывать до конца. Вопрос в анкете «слышал ли эту историю от одноклассников» |
| Заморозка сборки 31.12, а C-тексты пишутся в январе–феврале | Тексты нельзя добавить, не нарушив заморозку | **До 31.12 проверить**, что C-тексты загружаются как контент (новая contentVersion) без изменения сборки. Если нет — сдвинуть заморозку или сделать в сборке слоты для C-текстов |
| Эффект разный между сказками | Падает мощность (раздел 2.3), вывод нельзя обобщить | Вывод о 5 конкретных парах. Оценки по каждой паре публикуются как разведочные |

## Приложение А. Код и вывод

Все скрипты лежат в `docs/research-design/analysis/` и запускаются командой `python3 -I <скрипт>` (statsmodels 0.15.0, scipy 1.18.1). Генератор случайных чисел зафиксирован, поэтому повторный запуск даёт тот же вывод.

### А1. Аналитический расчёт выборки и мощности (`power_analytic.py`)

```python
"""Ertegi English, stage 1: analytic sample-size calculations.
All inputs except alpha/power/d are ASSUMPTIONS (see study-design.md, section 3).
Run: python3 -I power_analytic.py
"""
import math
from statsmodels.stats.power import TTestIndPower, TTestPower

ALPHA, POWER = 0.05, 0.80
DS = [0.3, 0.4, 0.5]
RS = [0.0, 0.5, 0.7]          # pretest-posttest correlation (0.0 = no covariate)
ICCS = [0.05, 0.10, 0.20]     # class ICC (assumption)
M = 25                        # students per class (assumption)
ind = TTestIndPower()
one = TTestPower()

def n_ind(d, r=0.0):
    """Per-group n, two-sample t, ANCOVA approximation: residual var = (1-r^2)."""
    d_eff = d / math.sqrt(1 - r**2)
    return math.ceil(ind.solve_power(effect_size=d_eff, alpha=ALPHA, power=POWER, ratio=1.0)) + (1 if r > 0 else 0)  # +1 df for covariate

print("A. Individual randomization (between-subjects), per group / total")
print(f"{'d':>4} " + " ".join(f"{'r='+str(r):>14}" for r in RS))
for d in DS:
    print(f"{d:>4} " + " ".join(f"{n_ind(d,r):>6} / {2*n_ind(d,r):>5}" for r in RS))

print("\nB. Same, randomized WITHIN class, class as fixed effect:")
print("   residual var ~ (1-r^2)(1-ICC); clustering does not inflate, it slightly helps")
for icc in ICCS:
    row = []
    for d in DS:
        for r in (0.5, 0.7):
            d_eff = d / math.sqrt((1 - r**2) * (1 - icc))
            n = math.ceil(ind.solve_power(effect_size=d_eff, alpha=ALPHA, power=POWER)) + 1
            row.append(f"d={d},r={r}: {2*n}")
    print(f"   ICC={icc}: " + "; ".join(row))

print(f"\nC. For contrast: classes randomized whole (cluster RCT), m={M}, DE = 1+(m-1)ICC")
for icc in ICCS:
    de = 1 + (M - 1) * icc
    cells = []
    for d in DS:
        n = n_ind(d, 0.7) * de
        cells.append(f"d={d}: {math.ceil(2*n)} students = {math.ceil(2*n/M)} classes")
    print(f"   ICC={icc} DE={de:.2f}: " + "; ".join(cells))

print("\nD. Within-subject (each student both conditions), paired t on condition difference")
print("   d is on the between-student SD scale; d_z = d / sqrt(2(1-rho)); rho = corr of a student's two condition scores")
for rho in (0.5, 0.7):
    cells = []
    for d in DS:
        dz = d / math.sqrt(2 * (1 - rho))
        n = math.ceil(one.solve_power(effect_size=dz, alpha=ALPHA, power=POWER))
        cells.append(f"d={d} (d_z={dz:.2f}): N={n}")
    print(f"   rho={rho}: " + "; ".join(cells))

print("\nE. What 2-4 classes give: enrolled -> analysable (consent x completion, assumption)")
for classes in (2, 3, 4):
    for m in (20, 25):
        for keep in (0.6, 0.7, 0.8):
            pass
rows = []
for classes in (2, 3, 4):
    for m in (20, 25):
        enrolled = classes * m
        rows.append((classes, m, enrolled, [math.floor(enrolled * k) for k in (0.6, 0.7, 0.8)]))
for c, m, e, a in rows:
    print(f"   {c} classes x {m} = {e} enrolled -> analysable at 60/70/80%: {a}")

print("\nF. Power actually achieved with N analysable (between, ANCOVA, total N split 1:1)")
for N in (34, 50, 70, 80):
    cells = []
    for d in DS:
        for r in (0.5, 0.7):
            d_eff = d / math.sqrt(1 - r**2)
            p = ind.power(effect_size=d_eff, nobs1=N / 2, alpha=ALPHA, ratio=1.0)
            cells.append(f"d={d},r={r}:{p:.2f}")
    print(f"   N={N}: " + " ".join(cells))

print("\nG. Power achieved, within-subject, N analysable")
for N in (34, 50, 70):
    cells = []
    for d in DS:
        for rho in (0.5, 0.7):
            dz = d / math.sqrt(2 * (1 - rho))
            cells.append(f"d={d},rho={rho}:{one.power(effect_size=dz, nobs=N, alpha=ALPHA):.2f}")
    print(f"   N={N}: " + " ".join(cells))

print("\nH. Minimal detectable effect (80% power) for N analysable")
for N in (34, 50, 70):
    mde_b = {r: ind.solve_power(nobs1=N/2, alpha=ALPHA, power=POWER) * math.sqrt(1 - r**2) for r in (0.5, 0.7)}
    mde_w = {rho: one.solve_power(nobs=N, alpha=ALPHA, power=POWER) * math.sqrt(2 * (1 - rho)) for rho in (0.5, 0.7)}
    print(f"   N={N}: between r=.5 d={mde_b[0.5]:.2f}, r=.7 d={mde_b[0.7]:.2f} | within rho=.5 d={mde_w[0.5]:.2f}, rho=.7 d={mde_w[0.7]:.2f}")
```

### А3. Симуляция на уровне слов, 5 пар (`power_sim5.py`)

```python
"""Ertegi English, stage 1: word-level simulation for 5 tale-pairs (each pair = folklore text + matched
control text sharing the SAME target words). Data are SIMULATED from ASSUMED parameters, not observed.
between: student reads all 5 pairs in one condition (randomised 1:1 within class).
within : student reads every pair once, 2 or 3 of 5 in folklore version; 20 lists (10 two-sets + complements),
         so each word is folklore for half the students.
Analysis A (primary in sims): student-level ANCOVA / paired difference with pretest covariate.
Analysis B (check): word-level logistic GLM with student + word fixed effects (conditional approx. of GLMM).
Run: python3 -I power_sim5.py
"""
import numpy as np, warnings
from scipy import stats
from itertools import combinations
import statsmodels.api as sm
warnings.filterwarnings("ignore")
rng = np.random.default_rng(20261104)
T = 5
SD_STUDENT, SD_GAIN, SD_WORD = 1.0, 0.5, 1.0     # ASSUMPTIONS (logit scale)
LISTS = [set(c) for c in combinations(range(T), 2)]
LISTS += [set(range(T)) - s for s in LISTS]       # 20 lists, balanced per tale

def gen(n, k, log_or, design, b_pre=-1.8, b_post=-0.7, sd_slope=0.0, sd_tale=0.0):
    W = T * k; tw = np.repeat(np.arange(T), k)
    u = rng.normal(0, SD_STUDENT, (n, 1)); g = rng.normal(0, SD_GAIN, (n, 1))
    w = rng.normal(0, SD_WORD, (1, W)); s = rng.normal(0, sd_slope, (n, 1))
    te = rng.normal(0, sd_tale, T)[tw][None, :]
    if design == "between":
        arm = np.zeros(n, int); arm[rng.permutation(n)[: n // 2]] = 1
        folk = np.repeat(arm[:, None], W, 1)
    else:
        idx = np.resize(rng.permutation(len(LISTS)), n); rng.shuffle(idx)
        folk = np.array([[int(tw[j] in LISTS[i]) for j in range(W)] for i in idx])
    pre = rng.random((n, W)) < 1 / (1 + np.exp(-(b_pre + u + w)))
    post = rng.random((n, W)) < 1 / (1 + np.exp(-(b_post + u + g + w + (log_or + s + te) * folk)))
    return pre, post, folk

def test_agg(pre, post, folk, design):
    n = pre.shape[0]
    if design == "between":
        arm = folk[:, 0]; y, x = post.mean(1), pre.mean(1)
        X = np.column_stack([np.ones(n), arm, x - x.mean()]); j = 1
    else:
        f = folk.astype(bool)
        y = np.array([post[i, f[i]].mean() - post[i, ~f[i]].mean() for i in range(n)])
        x = np.array([pre[i, f[i]].mean() - pre[i, ~f[i]].mean() for i in range(n)])
        X = np.column_stack([np.ones(n), x - x.mean()]); j = 0
    b, *_ = np.linalg.lstsq(X, y, rcond=None); df = n - X.shape[1]
    s2 = ((y - X @ b) ** 2).sum() / df
    t = b[j] / np.sqrt(s2 * np.linalg.inv(X.T @ X)[j, j])
    return 2 * stats.t.sf(abs(t), df)

def test_glm(pre, post, folk):
    """within design only: logit(post) ~ folk + pre + student FE + word FE."""
    n, W = pre.shape
    st = np.repeat(np.arange(n), W); wd = np.tile(np.arange(W), n)
    X = np.column_stack([folk.ravel(), pre.ravel().astype(float),
                         (st[:, None] == np.arange(1, n)).astype(float),
                         (wd[:, None] == np.arange(1, W)).astype(float), np.ones(n * W)])
    try:
        r = sm.GLM(post.ravel().astype(float), X, family=sm.families.Binomial()).fit(method="newton", maxiter=50)
        return r.pvalues[0]
    except Exception:
        return np.nan

def power(n, k, OR, design, sims=1000, **kw):
    return np.mean([test_agg(*gen(n, k, np.log(OR), design, **kw), design) < .05 for _ in range(sims)])


if __name__ == "__main__":
    k = 5
    print(f"T={T} tale-pairs x k={k} target words = {T*k} words; pretest ~20% known, delayed control ~35% (ASSUMED)")
    # implied d for each OR: see implied_d.py (OR 1.3/1.5/1.8 ~ d 0.22/0.34/0.49)
    print("\nPower, analysis A (1000 sims each)")
    print("   N  " + "  ".join(f"btw{o} wth{o}" for o in (1.3, 1.5, 1.8)))
    for n in (30, 40, 50, 60, 80, 100):
        cells = []
        for OR in (1.3, 1.5, 1.8):
            cells += [f"{power(n,k,OR,'between'):.2f}", f"{power(n,k,OR,'within'):.2f}"]
        print(f"{n:>4}  " + "    ".join(cells))
    print("\nType I error (OR=1, N=50):", {d: round(power(50, k, 1.0, d, 2000), 3) for d in ("between", "within")})
    print("\nSensitivity, within, OR=1.5, N=50/60/80 (1000 sims):")
    for lab, kw in [("base", {}), ("k=4 words/pair", {"k": 4}), ("k=6", {"k": 6}),
                    ("pretest 35% known (b_pre=-0.9,b_post=0.2)", {"b_pre": -0.9, "b_post": 0.2}),
                    ("SD student slope 0.3", {"sd_slope": 0.3}), ("SD tale effect 0.3", {"sd_tale": 0.3}),
                    ("SD slope 0.5 + tale 0.5", {"sd_slope": 0.5, "sd_tale": 0.5})]:
        kk = kw.pop("k", k)
        print(f"  {lab:45s}: " + " / ".join(f"{power(n, kk, 1.5, 'within', **kw):.2f}" for n in (50, 60, 80)))
    print("\nCheck: analysis B (word-level logistic, student+word FE), within, 300 sims")
    for n, OR in [(50, 1.0), (50, 1.5), (60, 1.5)]:
        ps = [test_glm(*gen(n, k, np.log(OR), "within")) for _ in range(300)]
        print(f"  N={n}, OR={OR}: rejection rate {np.nanmean(np.array(ps) < .05):.3f}")
```
