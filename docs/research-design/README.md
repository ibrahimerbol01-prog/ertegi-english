# Дизайн исследования (черновики)

Черновики к этапам 0 и 1, подготовлены 04.11.2026 агентами Claude и проверены выборочно. Это не утверждённые документы: решения принимают автор и научный руководитель.

- `literature-review.md` — обзор литературы, предварительный: часть источников не открыта, у каждой записи стоит метка проверки. Три цитаты проекта (Laufer 1989, Hu & Nation 2000, Covington & McFall 2010) не подтверждены.
- `study-design.md` — гипотезы, расчёт выборки, рекомендованный дизайн (внутрисубъектный, по парам текстов), план анализа, протокол этапа 0, схема теста A/B, риски. Все числа — расчёты при явных допущениях, не данные учеников.
- `analysis/` — скрипты расчёта мощности и отбора целевых слов с выводом (`python3 -I <скрипт>` из корня репозитория).
