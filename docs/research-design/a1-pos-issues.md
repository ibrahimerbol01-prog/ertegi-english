## 4. Один пример на разные части речи

У **62 слов** один и тот же пример висит на двух-трёх частях речи. Значит, хотя бы у одной из них пример не подходит. Например:

- black (adjective и noun);
- close (adjective и verb);
- like (preposition и verb);
- to (infinitive-to и preposition);
- that (conjunction, determiner и pronoun);
- work (noun и verb).

Полный список выдаёт команда ниже. Кажется, пример подбирали по совпадению формы, без учёта части речи и регистра.

```bash
python3 -I -c "
import json,collections
d=json.load(open('src/data/wordbank/A1.json'))
by=collections.defaultdict(list)
for x in d:
    if x.get('example'): by[(x['word'],x['example']['text'])].append(x['pos'])
print(sorted((w,p) for (w,t),p in by.items() if len(p)>1))"
```
