# Общий опыт команды ИИ — читать в начале КАЖДОЙ сессии

Здесь опыт всех исполнителей (Claude, Gemini и будущих). Модели не переобучаются — вместо этого
команда учится через этот файл: каждый пишет, что сработало и где ошибся, все читают перед работой.
Пополняет диспетчер из строк «Урок:» и «Сработало:» в отчётах. Новое — сверху раздела.

## Сработало — делай так же

- **Проверка тестов «на мутациях»** (Claude, Задание 2): временно ломаешь защиту в коде — тест должен
  упасть; вернул — зелёный. Так видно, что тест реально что-то проверяет.
- **Двойная защита исследования** (Claude, Задание 5): `RESEARCH_MODE ? null : lazy()` недостаточно —
  чанки всё равно собираются; нужна ещё alias-заглушка в vite.config.ts. Проверять реальной сборкой
  `VITE_RESEARCH_MODE=1` и поиском строк данных в dist.
- **Замер вместо оценки** (Claude, Задание 5): размер бандла gzip до/после, как в performance-baseline.md.
  Чего не измерил — честно «не измерял», без выдуманных цифр.
- **Числа — командой, не на глаз**: `wc -l`, `python -c "...csv..."`. Ошибка «4 685 строк» была от оценки.
- **Сверка источника по странице журнала/DOAJ** (Gemini, Novita 2023): когда источники расходятся,
  доверять странице издателя, а расхождение описать в примечании.
- **wip-пуши** после каждого куска: выключенный ноутбук не стёр ни строчки работы.
- **Отчёт по формату** (итог / изменено / проверки / ссылка / вопросы): диспетчер проверяет за минуту.

## Грабли — не повторять

- Лицензию, DOI, том, год, число строк — не «по памяти». Были: «CC BY» без лицензии, DOI 10.64152/…
  вместо handle, том 23(3) вместо 23(1).
- Округлять статистику («>0,80») нельзя — дословно с разделом источника.
- Выводы на студентах вуза ≠ выводы на школьниках: «согласуется с», не «подтверждается».
- Windows: `core.longpaths true`; CRLF ломает побайтные тесты; исходные данные «как в источнике»
  не перекодировать (`-text` в .gitattributes).
- Перед новой работой — `git ls-remote --heads origin`: нет ли уже такой ветки.
- Новая функция приложения — всегда выключена в исследовательском режиме и без целевых слов теста.
- Без выбранной папки проекта Claude Code не запускает команды; без Node.js проверки не идут — сначала окружение.
